# ValuePoint

An entry (x, y) in a table formula

## Active bindings

- `x`:

  The x value of the point.

- `y`:

  the y value of the point.

- `restartSolver`:

  Indicates whether the solver should be restarted when this point is
  reached. Default is `FALSE`
