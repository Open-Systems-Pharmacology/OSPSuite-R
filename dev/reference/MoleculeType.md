# Molecule Types

Allowed types for molecules in a `Molecules` building block. Values are
`Drug`, `Metabolite`, `Enzyme`, `Transporter`, `Binding Partner`,
`Complex`, and the umbrella `Protein` (= `Enzyme` + `Transporter` +
`Binding Partner`). Used to filter molecule names via
`MoleculesBuildingBlock$allMoleculeNamesOfType()`.

## Usage

``` r
MoleculeType
```

## Format

An object of class `list` of length 7.
