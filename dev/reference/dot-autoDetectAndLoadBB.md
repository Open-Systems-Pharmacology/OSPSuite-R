# Auto-detect the building block type stored in a pkml file and load it. Returns a list with `net` (the loaded reference) and `type` (the resolved `BuildingBlockTypes` value).

Auto-detect the building block type stored in a pkml file and load it.
Returns a list with `net` (the loaded reference) and `type` (the
resolved `BuildingBlockTypes` value).

## Usage

``` r
.autoDetectAndLoadBB(expandedPath)
```
